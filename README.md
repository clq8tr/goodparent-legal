# Good Parent — legal pages

The public Privacy Policy and Terms of Service for the Good Parent app,
by The Good Company.

- https://clq8tr.github.io/goodparent-legal/privacy.html
- https://clq8tr.github.io/goodparent-legal/terms.html

These pages are GENERATED from `src/content/legal.ts` in the app's own
repository, which is the same text the app displays on screen — so the
published policy and the in-app one cannot drift apart. Do not hand-edit
them here; change the app and run `npm run legal`, then copy the output.

This repository is public only because both app stores require a privacy
policy at a reachable URL. It contains no application source.
